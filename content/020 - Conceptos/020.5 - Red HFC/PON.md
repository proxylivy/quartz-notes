# Info
**P**assive **O**ptical **N**etwork o Red Optica Pasiva es una arquitectura FTTH basado en [[020 - Conceptos/020.5 - Red HFC/Fibra Optica|Fibra Optica]] donde multiples usuarios comparten una misma fibra mediante splitters pasivos

La estructura fisica es similar: OLT (Central) -> Red de distribucion -> ONT (Cliente)

Pero su trafico tiene 2 grandes variantes, GPON y EPON


Es uno de los [[020 - Conceptos/020.5 - Red HFC/Tipos de Red Fibra Optica|Tipos de Red Fibra Optica]], que se separa en
- GPON (FO)
	- Entidad Normativa: ITU-T
	- Normas
		- Serie G.984 (G.984.1/.2/.3/.4)
		- Serie G.987 para 10G-PON
- EPON (Ethernet)
	- Entidad Normativa: IEEE
	- Normas
		- IEEE 802.3ah-2004 (1GE)
		- IEEE 802.3av-2009 (10GE)
		- IEEE 802.3bk-2013 (10GE)
		- IEEE 802.3ca-2020 (25GE y 50GE)
