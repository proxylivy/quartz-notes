# Info
Un AP (**A**ccess **P**oint) es un dispositivo de red que proporciona conectividad inalambrica

Usualmente se conecta a un [[020 - Conceptos/020.4 - Dispositivos de Red/Switch|Switch]] y utiliza esta conexion como enlace hacia la red de distribucion para dispositivos finales, como telefonos, computadores, etc.

Puede funcionar de manera autonoma o ser administrado de forma centralizada mediante un WLC (Wireless LAN Controller)
