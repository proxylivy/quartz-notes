# Info

Objetivo: Confeccionar un Mapa Conceptual mediante el software [CmapTools](https://cmap.ihmc.us/cmaptools/) ([Win](https://cmapdownload.ihmc.us/installs/CmapTools/Win/) | [Linux](https://cmapdownload.ihmc.us/installs/CmapTools/Linux/)) (Wacala), luego de haber indagado y profundizado en los elementos fundamentales (activos y pasivos) para la transmisión de datos en una red de servicios básicos de telecomunicaciones

Deben crear un Mapa Conceptual con los siguientes conceptos
- Elementos pasivos de red.
- Elementos activos de red.
- Cable coaxial.
- Conector F.
- Cable TP.
- Conector RJ 45.
- Cable telefónico.
- Roseta telefónica.
- Conector RJ11.
- TAP.
- Splitter.
- Acoplador DC.
- MTA (Cable Modem).
- Router Inalámbrico.
- Teléfono.
- D-Box.
- Impedancia.
- Atenuación.
- Ganancia.
