# Info

Se basa en:
- Instalacion y configuracion de Windows Server y Linux
- Configurar Servicios como [[010 - Protocolos/010.3 - Comunicaciones/DHCP|DHCP]], [[010 - Protocolos/010.3 - Comunicaciones/DNS|DNS]], [[010 - Protocolos/010.3 - Comunicaciones/010.3.4 - IP/IP|IP]] ([[010 - Protocolos/010.3 - Comunicaciones/010.3.4 - IP/IPv4|IPv4]] | [[010 - Protocolos/010.3 - Comunicaciones/010.3.4 - IP/IPv6|IPv6]]), HTTP (IIS), FTP (IIS)
- Configuracion de Particiones
- Enviar archivos entre maquinas Linux con HTTP y FTP
- Crearse cuentas para Google Cloud, AWS y Azure

> [!IMPORTANT] Sobre Windows Server 2016
> Windows Server 2016 comparte una base y una experiencia muy parecida a Win 10. Para este ramo (Hecho en 2017), la mayoria de procedimientos son equivalentes en 2016, 2019 y 2022.
> 
> Pero hazte un favor, utiliza *Windows Server 2022*. Es la ultima de la rama parecida a Win 10 y tiene aun soporte.
> 
> Yo dire "Windows Server 2016" porque es la version de referencia del ramo, pero cuando leas eso, piensa en "Windows Server 2022" para tus experimentos. No caigas en utilizas cosas viejas solo porque si...
